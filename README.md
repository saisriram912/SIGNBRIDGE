# SIGNBRIDGE
SignBridge AI is a smart wearable assistive system that uses flex sensors and motion sensors to recognize sign language and convert gestures into text and speech. It features learning and assessment tools with real-time feedback, along with an AI-assisted communication mode for phone calls, empowering deaf and hard-of-hearing individuals.
# SignBridge AI – Sign Language Learning and Translation Platform

## About the Project

SignBridge AI is a web-based prototype designed to support sign language communication and learning for deaf and hard-of-hearing individuals. It provides an interactive interface for exploring sign language translation, practising predefined signs, and tracking learning progress.

## Features

### 1. Translation Mode
- Interactive sign language translation interface.
- Displays recognised or selected sign vocabulary as text.
- Speech output for supported translations.
- Confidence-based speech output with a cooldown mechanism.

### 2. Learning Mode
- Allows users to select predefined signs for practice.
- Provides an interactive learning experience.
- Tracks practice attempts and accuracy.
- Displays learning progress and performance analytics.

### 3. Performance Tracking
- Records learning attempts.
- Calculates practice accuracy.
- Displays progress through an analytics dashboard.
- Helps users monitor their learning performance.

## Technologies Used

- **HTML5** – Webpage structure.
- **CSS3** – Styling and responsive user interface.
- **JavaScript** – Application logic and interactive functionality.
- **Web Speech API** – Speech output in supported browsers.

## Getting Started

### Prerequisites
- A modern web browser such as Google Chrome or Microsoft Edge.
- No additional software installation is required.

### Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Open `signbridge_demo.html` in your web browser.

4. Explore the Translation Mode and Learning Mode.

## Current Project Scope

This repository contains the front-end software prototype of SignBridge AI. It demonstrates the user interface, predefined sign vocabulary, interactive learning features, speech output, and basic performance tracking.

**Note:** This version is a software prototype. It does not currently implement live camera-based sign recognition or physical wearable hardware integration.

## Future Enhancements
